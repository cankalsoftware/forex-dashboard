# 📈 Antigravity Forex Predictor Dashboard

A full-stack, machine-learning-driven Forex analysis and prediction platform built with **Next.js 16 (React 19)**, **TailwindCSS**, **FastAPI (Python)**, and **PyTorch / XGBoost**.

---

## 🚀 Quick Start (How to Run)

To run the entire app locally, open **two terminal windows**:

### 1️⃣ Terminal 1: Backend (FastAPI Python)
```powershell
cd backend
.\venv\Scripts\python.exe run.py
```
*Runs on `http://localhost:8000`*

### 2️⃣ Terminal 2: Frontend (Next.js)
```powershell
cd frontend
pnpm dev
# or: npm run dev
```
*Runs on `http://localhost:3000`*
